По месяцам

Копия в файл

Данные хранятся на этом телефоне. Копию можно сохранить в файл — например, в «Загрузки» или Google Диск.

Облачная копия

После каждого изменения приложение само отправляет копию в ваш приватный репозиторий на GitHub. На новом телефоне её можно восстановить.

Как получить токен
  1. Создайте приватный репозиторий: github.com/new, имя kommunalka-data, тип Private.
  2. Откройте создание токена.
  3. Expiration — выберите срок. Когда токен истечёт, приложение об этом скажет.
  4. Repository access → Only select repositories → kommunalka-data.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Нажмите Generate token, скопируйте его и вставьте ниже.

О приложении

Учитываются шесть услуг: холодная вода, горячая вода (носитель и энергия), электроэнергия день и ночь, водоотведение. ОДН, СОИ, содержание, отопление, ТКО, капремонт и прочее не учитываются. Суммы берутся из столбца «Начислено по тарифу».
