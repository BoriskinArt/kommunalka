# Коммунальные платежи — PWA для Android

Учёт шести коммунальных услуг по квартирам № 76, 211, 231. Поддерживается ручной ввод, распознавание PDF и фото, история, сравнение месяцев и резервная копия. Работает без интернета.

## Как установить на телефон

Чтобы приложение установилось на Android, оно должно открываться по HTTPS. Из файла на телефоне (`content://…`) установка не работает.

1. На компьютере выполните `./build.sh` — появится папка `dist/` и архив `kommunalka-dist.zip`.
   В сборку не попадают папка `tests/` и ваши квитанции.
2. Опубликуйте папку `dist/` на любом бесплатном HTTPS-хостинге:
   - **Netlify** — https://app.netlify.com/drop: войдите и перетащите папку `dist` в окно. Получите адрес вида `https://….netlify.app`.
   - **GitHub Pages** — создайте репозиторий, загрузите содержимое `dist/` и включите Pages в Settings → Pages.
   - **Cloudflare Pages** — Upload assets → папка `dist`.
3. Откройте адрес в Chrome на телефоне → меню ⋮ → **«Добавить на главный экран» / «Установить приложение»**.

После первого запуска приложение работает без интернета. Модуль распознавания фото (~9 МБ) докачивается в фоне.

## Кирова, 40

Отдельная вкладка с отдельным учётом: вода и водоотведение, отопление, электричество и одна своя строка. Для каждой строки есть тариф и показания: предыдущее показание и тариф подставляются из прошлого месяца, а сумма считается как расход × тариф. К расходу электричества добавляется 1 % потерь. У отопления показаний нет: вводится только сумма, рядом видна сумма прошлого месяца. Внизу показаны итог и сумма с налогом 6 % (итог / 0,94: после уплаты 6 % остаётся ровно итог), а также отметка «Оплачено». Всё сохраняется само. В итоги квартир эти данные не входят, но попадают в ту же резервную и облачную копию (раздел `kirova`).

## Облачная копия (GitHub)

В разделе «Ещё → Облачная копия» можно подключить приватный репозиторий GitHub. После каждого изменения приложение отправляет туда файл `kommunalka-backup.json`. Все версии остаются в истории коммитов репозитория. Без интернета изменения копятся и отправляются, когда связь появится.

Нужен fine-grained токен с доступом только к этому репозиторию и правом **Contents: Read and write**. Пошаговая инструкция есть в самом приложении. Токен хранится только на телефоне и в резервную копию не попадает.

На новом телефоне подключите тот же репозиторий и выберите «Взять из облака».

## Обновление

Измените версию в `sw.js` (`VERSION`) и `js/app.js` (`APP_VERSION`), затем снова выполните `./build.sh` и опубликуйте `dist/` **по тому же адресу**.
История хранится в IndexedDB на телефоне, и обновление её не затрагивает. Если опубликовать приложение по другому адресу, получится отдельное приложение с пустой базой. Данные в него переносятся через «Ещё → Сохранить копию / Восстановить из копии».

## Как работает распознавание

- **Текстовый PDF** — текст читается напрямую через PDF.js, OCR не используется. Сумма берётся по координатам из столбца «Начислено по тарифу». Затем она сверяется с «объём × тариф»: если сходится, рядом стоит ✓.
- **Скан PDF и фото** — распознаются через Tesseract (русский язык). Перед распознаванием можно повернуть изображение, перетащить 4 угла рамки (это обрезка плюс выпрямление перспективы) и усилить контраст. Мелкий текст автоматически увеличивается.
- **Строки ОДН, СОИ и общего имущества** исключаются всегда. Содержание жилья, отопление, ТКО, капремонт, охрана и прочее не учитываются.
- **Нечитаемая сумма** остаётся пустой с пометкой «введите вручную». Приложение не угадывает её по соседним значениям или итогу.
- **Сумма с фото** без сверки «объём × тариф» подсвечивается жёлтым с пометкой «проверьте».
- **Услуга не найдена на фото** — поле остаётся пустым, ноль не ставится. Ноль подставляется автоматически только для текстового PDF, где таблица прочитана целиком.
- **Номер квартиры и месяц** определяются из квитанции, но их можно изменить. Лицевой счёт запоминается после первого сохранения, и следующие квитанции с ним определяются автоматически.
- **Повторная запись**: если за эту квартиру и месяц запись уже есть, приложение спросит, заменять ли её.

## Тесты

```bash
npm i --prefix /tmp/kt pdfjs-dist@4.10.38
node tests/run-tests.mjs /tmp/kt/node_modules/pdfjs-dist/legacy/build/pdf.mjs
```

Тесты проверяют контрольные примеры из ТЗ, около 90 вариантов названий услуг, исключение ОДН/СОИ, а также разбор двух реальных квитанций: ЕПД МосОблЕИРЦ и «Антей+».

| `js/kirova.js` | Вкладка «Кирова 40» |
| `sw.js`, `manifest.webmanifest` | Офлайн-режим и установка |
